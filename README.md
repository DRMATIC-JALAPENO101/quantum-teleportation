# Quantum Teleportation Streamlit Demo

Interactive quantum teleportation visualization built with Streamlit, Qiskit, NumPy, and Matplotlib.

## Run locally

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL printed by Streamlit, usually `http://localhost:8501`.

## Deploy with Streamlit Community Cloud

1. Push this project to a GitHub repository.
2. In Streamlit Community Cloud, choose **New app**.
3. Select the repository, branch, and `app.py` as the main file.
4. Deploy.

`requirements.txt` is included so Streamlit Cloud installs the required quantum-computing dependencies automatically.
